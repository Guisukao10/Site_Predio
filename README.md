# Site Prédio — Residencial André Bernardes (Mococa, SP)

Protótipo do site de pré-lançamento. Página estática (HTML + CSS + JS puro, sem build).

- `index.html` — página única com animações ligadas à rolagem
- `assets/` — renders em WebP, mapas de profundidade (efeito 2.5D) e quadros da cena gerada por IA (`assets/film/`)

Deploy: Vercel (projeto estático, sem framework).
